The Breast Cancer Wisconsin dataset consists entirely of numerical features with moderate class imbalance, making it suitable for distance-based, tree-based, and margin-based classifiers. Features were standardized to ensure fair distance computation for KNN and stable margin estimation for SVM. KNN was chosen as a simple baseline to capture local neighborhood structure after scaling. A Decision Tree with entropy was used to model non-linear relationships, with maximum depth tuned to control overfitting and optimize the F1-score. A linear SVM was selected due to the near-linear separability of the data, and its strong generalization is supported by the relatively small number of support vectors defining a wide margin. F1-score was preferred over accuracy to better handle class imbalance and reduce false negatives in medical diagnosis.
